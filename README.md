# LaneSync release approvals

This branch is maintained by [LaneSync](https://lanesync.dev). It records who approved each
release candidate for production, and the evidence they approved.

- Each release has a file in `releases/`. Its history shows every candidate and approval.
- Approving never adds commits to your code: this branch shares no history with it.
- Don't delete this branch or push to it directly. LaneSync protects it with a ruleset.

Learn more: https://docs.lanesync.dev/guides/evidence-approval
